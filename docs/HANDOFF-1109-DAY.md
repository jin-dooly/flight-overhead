### 1-5. 하늘 모드

- 폰 방향 센서 연결: 아이폰은 `webkitCompassHeading`, 안드로이드는 북쪽 기준 센서 값으로 폰 뒷면 방향 계산. 올려다보는 각도는 지평선 아래(음수)까지 그대로
- 권한은 "센서 켜고 시작하기" 클릭 안에서 요청(아이폰 조건)
- 거부, 미지원, 나침반 값이 3초 안에 안 옴 → 끌어서 둘러보기로, 위에 이유와 기기별 켜는 방법, 다시 시도
- 가로 화면이면 "폰을 세로로 들어 주세요"
- 자세한 내용: `HANDOFF-SKY.md` 5번

### 1-6. 배포 환경

- `VITE_MQTT_URL`이 없으면 HTTPS 페이지(배포, Vercel 미리보기)는 배포 서버로 붙음. 미리보기에 이 변수가 없어서 폰에서 지도가 안 떴던 문제
- MQTT 연결을 만들다 오류가 나도 앱이 멈추지 않음
