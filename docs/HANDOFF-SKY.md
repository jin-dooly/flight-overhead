## 2. 무엇을 만들었나

**화면 흐름 (`pages/SkyPage.tsx`)**

- 폰(주 입력이 터치): 시작 화면 → "센서 켜고 시작하기" → 하늘 화면
- 폰이 아님(데스크톱): "하늘 모드는 폰에서 열어 주세요" 대화 상자. 주소 복사, 지도로 돌아가기, **"센서 없이 화면 미리 보기"**(리뷰어가 PC에서도 화면을 볼 수 있게)
- 폰 여부는 `(pointer: coarse)`로 판단. 데스크톱 브라우저도 `DeviceOrientationEvent`를 갖고 있어서 센서 API 유무로는 구분이 안 됩니다.

**계산 (`lib/sky.ts`, 순수 함수 + 테스트)**

- `skyDirection(나, 비행기)`: 방위각(`bearingDeg`, 따라가기에서 만든 함수 재사용)과 올려다보는 각도 = `atan2(고도, 지상 거리)`. 기획서 "위아래 = 고도와 거리로 계산"
  - 테스트: 10km 떨어진 10km 고도 → 45도, 목업 값(5.9km, 8,000ft) → 약 22도
- `projectToScreen`: 좌우는 (방위각 - 폰 방향), 위아래는 (각도 - 폰 기울기)에 1도당 px를 곱함. 목업처럼 화면 폭 = 약 90도
- `angleDiff`: 북쪽을 사이에 둔 차이를 짧은 쪽으로(350도와 10도는 20도)
- `pickLocked`: 조준 원(반지름 44px) 안에서 가운데에 가장 가까운 비행기

**하늘 화면 (`components/sky/SkyView.tsx`, 목업 SkyMain)**

- 위: "북동 36°", 나침반 띠(5도 눈금, 45도마다 방위 이름), 상태 칩
- 가운데: 10도마다 각도 눈금, 지평선과 땅, 조준 원, 비행기(조준한 비행기는 크게 + 파란 라벨)
- 아래: 조준한 비행기 카드(편명, 나와의 거리, 고도, 올려다볼 각도, 속도, "지도에서 보기" → 지도에서 그 비행기가 선택된 상태로)
- 처음에는 가장 가까운 비행기 쪽을 바라보게 해서, 들어오자마자 하나가 조준 원에 들어옵니다.
- 비행기 위치는 1초마다 예상 위치로 다시 계산합니다(하늘에서는 천천히 움직여 보여서 매 프레임일 필요 없음).

**뒤로가기 (`hooks/useMode.ts`의 `goBackOr`)**

- 기존에는 "지도로 돌아가기"가 `history.back()`이라, `?mode=sky` 링크로 바로 들어온 사람이 누르면 사이트를 떠났습니다.
- 앱 안에서 이동할 때 `pushState({ fromApp: true })`로 표시하고, 표시가 있을 때만 뒤로가기, 없으면 지도 모드로 바꿉니다.

## 3. 내린 결정

- 센서 대신 끌어서 둘러보기. 요청 범위가 UI까지라서, 화면을 확인할 수 있는 가장 단순한 입력으로 대신함.
- 하늘에 그리는 비행기는 지도와 같은 반경(20km, 넓히면 30km) 안의 비행기. 고도를 모르는 비행기는 위치를 정할 수 없어 그리지 않음.
- 나와의 거리는 지도 카드와 같게 지상 거리(직선 거리 아님).
- 폰이 아닐 때 대화 상자 뒤 배경은 목업의 흐린 지도 대신 하늘 배경색. 지도를 한 번 더 그리지 않으려고.

## 4. 남은 작업 (다음에 할 것)

1. **센서 연결:** `SkyView`의 `look.heading`, `look.pitch` 두 값을 `deviceorientation`(iOS는 `webkitCompassHeading`, 안드로이드는 `deviceorientationabsolute`의 `alpha`)에서 받도록 바꾸면 됩니다. 계산과 화면은 그대로 씁니다.
   - iOS는 `DeviceOrientationEvent.requestPermission()`을 "센서 켜고 시작하기" 버튼 클릭 안에서 불러야 합니다(지금 버튼 자리).
   - 거절하면 보여 줄 화면은 목업에 없어서, 기획서에 추가가 필요합니다.
   - 센서 값의 떨림을 줄이는 필터(이동 평균 등)가 필요할 수 있습니다.
2. **HTTPS에서 확인:** 센서와 위치 API는 HTTPS에서만 동작해서(기획서), 배포 환경에서 실제 폰으로 확인해야 합니다.
3. **아래를 볼 때:** 지금은 기울기를 0~85도로 묶었습니다. 폰을 땅으로 향할 때의 표시는 정하지 않았습니다.
